Installing FoolFuuka X on Chrome:
1. Go to "Manage extensions" in Chrome
1. Enable Developer mode
2. Click "load unpacked" in the extensions area
3. Add the "ghost_filter_extension" folder

Installing FoolFuuka X on Firefox:
1. Click "Manage extensions"
2. Enter the Mozilla addons search window/site and search for "FoolFuuka X"
3. Install FoolFuuka X from the Mozilla Addons.
4. Or download it directly from this link at [https://addons.mozilla.org/en-US/firefox/addon/foolfuuka-x/](https://addons.mozilla.org/en-US/firefox/addon/foolfuuka-x/)
