Installing FoolFuuka X:
1. Enable developer mode on chrome
2. Click "load unpacked" in the extensions area
3. Add the "ghost_filter_extension" folder

Known glitches/bugs:
FoolFuuka X is designed to remove the 404 4chan errors when visiting links in Desuarchive that aren't actually archived on the site, and part of getting this to work required injections into 4chan.org itself. This causes bugs when you try to open threads on 4chan with FoolFuuka enabled, and you are re-directed to the archived.moe or arch.b4k.dev thread instead. Until we can fix this, do not use the main 4chan with this extension enabled.
